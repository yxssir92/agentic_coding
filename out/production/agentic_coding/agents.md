# Anweisungen für die Projektarbeit

- Autor: Yassir (GitHub: yxssir92).
- Dieses Projekt ist ein einfaches Java-Konsolenspiel für einen Einsteiger.
- Verwende strukturierte Programmierung mit einfachen Klassen, Methoden, Arrays, Bedingungen und Schleifen.
- Verwende keine Vererbung, Interfaces, abstrakten Klassen, Collections, Streams, Lambdas oder Frameworks.
- Halte den Code in `Wordle.java` und ergänze nur notwendige Funktionen.
- Erkläre Änderungen mit verständlichen Kommentaren und aktualisiere `code-erklaerung.md`.
- Halte `readme.md` und die nummerierte Funktionsliste in `features.md` aktuell.
- Prüfe nach Änderungen die Kompilierung mit `javac -encoding UTF-8 Wordle.java` und starte das Spiel mit `java Wordle`.
- Prüfe besonders ungültige Eingaben, Sieg, Niederlage und doppelte Buchstaben.
- Lade keine kompilierten `.class`-Dateien oder IDE-Einstellungen ins Repository hoch.
